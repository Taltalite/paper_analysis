# 人工标注文献指南（学术文献问答与 figure 证据追溯）

> 2026-10-09 审核版。配套材料：`evals/annotation/blank.json`（空白模板）、
> `evals/annotation/ANNOT-01.json`～`ANNOT-05.json`（绑定 `ref_baseline/gkaf795.pdf` 的五个示例任务）、
> `evals/qa_candidates.jsonl`（16 条候选问题）、`evals/qa_README.md`（验证边界）。
> 本指南是操作规范；模板字段的逐字段说明见 `evals/annotation/README.md`。

## 0. 标注的目的与定位

人工标注是系统效果评估的唯一金标准来源。工程测试（fake 模型、合成 PDF、API 回归）只能证明
"实现和失败处理正确"，不能证明"答案内容正确"。只有冻结的人工参考才能计算：

- 逐主张正确率（claim correctness）
- 引文/证据定位正确率（页码、块、图号、子图）
- 目标子图对齐率（panel alignment）
- 必需主张召回率（required claim recall）
- 拒答正确率（该拒则拒）

三类结果必须分开记录：**实现验证**、**真实调用**、**效果验证**。
调用成功 ≠ 回答正确；工程检查通过 ≠ 人工正确性评分。

## 1. 标注前准备

1. 选论文：选择你有权使用的单篇 PDF，优先覆盖分子生物学、生物信息学、表观遗传学领域，
   兼顾不同版式（单栏/双栏）、不同图表类型（柱状图、曲线、热图、显微图、流程图）。
2. 登记论文：计算并记录 SHA-256（`sha256sum 文件.pdf`）、题名、DOI、页数、难度标签。
   参考 `evals/datasets/paper_v1` 的清单格式。文件一旦更换或重新下载，必须重新绑定。
3. 选题：每篇论文 8–12 条核心问题/主张。问题应覆盖：
   - 纯正文证据（方法、对照、统计量）；
   - 图注证据（caption 明确陈述的内容）；
   - 视觉证据（必须实际看图才能回答的内容，如坐标轴、颜色、走势、小标签）；
   - 负例：不存在的图/子图、论文未报告的数据（用于验证拒答与 `not_reported` 行为）。
4. 绑定图号与子图：视觉类问题必须指定具体 `figure` / `panel`（如 `2` / `a`），
   并在 PDF 物理页码（从 1 开始）下核对。

## 2. 证据记录规则（先找证据，再写答案）

每条证据编号 `E1`、`E2`…，关键字段：

- `source_kind`：三选一，不可混淆——
  - `text`：正文/方法/结果的文字；
  - `caption`：图注文字（"图注说阴影是标准差"属于此类）；
  - `vision`：亲眼在图中看到的（"曲线周围有阴影"才是视觉观察）。
- `pdf_page_1_based`：PDF 物理页码，不用论文印刷页码。
- `verbatim_quote`：text/caption 证据必须逐字摘录原文，保留修饰符、单位和条件；
  纠正排版断行不能改变内容。
- `visual_observation`：vision 证据用中文描述真正可见的坐标轴、标签、颜色、走势或数值；
  不能把图注复述标为视觉金标准。
- `block_id` / `bbox`：不知道就留 `null`，不编造。bbox 若填写，用 PDF 点坐标
  `[x0, y0, x1, y1]`（左上原点），并在同页验证。
- `legibility`：`clear` / `ambiguous` / `unreadable` / `not_applicable`。
  读不清的上标、小字不可按领域常识补全，也不可参考模型答案补全。

## 3. 参考答案（gold_claims）规则

- 每条主张只写一个可独立判断的事实，`claim_id` 用 G1、G2…；
- `statement` 用简体中文陈述；`basis` 标 `text` 或 `visual`；`evidence_ids` 引用本文件的 E 编号；
- 图文混合结论拆成多条，分别绑定证据；
- `required=true` 表示完整回答不可缺少；`false` 为可选补充；
- `expected_status`：
  - `answered`：证据足以完整回答；
  - `partial`：只能部分回答，必须写明剩余不确定性；
  - `refused`：证据不足（含目标图不存在），应拒答。拒答题 `gold_claims` 可为空，
    但必须记录拒答理由和查找范围；
- `required_uncertainties`：答案必须说明的限制；
- `forbidden_inferences`：不允许的推断（如从相关性推因果、从曲线估未标注的数值）。

## 4. 双人标注与仲裁

1. 复制任务文件为 `ANNOT-XX.A.json` / `ANNOT-XX.B.json`，两人独立标注；
   标注期间不看模型答案、不看历史冒烟结论、不看对方文件。
2. 独立完成后将 `annotation_state` 改为 `已独立标注`。
3. 比对分歧：主张粒度、证据来源归类、可读性、期望状态。逐条记入
   `adjudication.disagreements`，由第三人或讨论仲裁；两份原始标注都保留。
4. 合并文件记录 `reviewer_ids`、`resolution`、`frozen_at`（ISO 8601），
   状态设为 `已仲裁冻结`。未解决的分歧不进入正式计分集。
5. 暂时只有一人标注时，状态标 `单人初标待复核`，不得声称双人金标准。
   冻结后再修改必须另存版本并说明原因。

## 5. 评价模型答案（冻结之后才进行）

1. 金标准冻结后才打开模型输出，记录 `evaluation.answer_id` 和 `run_id`。
2. 逐条评审模型输出主张，填写 `claim_reviews`：
   - `matched_gold_claim_ids`：对应哪些金标准主张；
   - `correctness`：`correct` / `incorrect` / `unverifiable`；
   - `citation_correct`：引文页码/块/摘录是否真实对应（true/false/不适用 null）；
   - `panel_aligned`：视觉主张是否对准目标子图；
   - `reason`：人工判定理由。
3. 模型答对但金标准没列的额外主张：人工核查后如实记录，不能直接判错，
   也不能事后悄悄并入原金标准（另存版本）。
4. 漏掉的必需主张写入 `missed_gold_claim_ids`；对比期望状态填 `expected_status_match`。
5. 汇总指标时分别报告分子、分母、不适用项和样本数：
   - 拒答题没有输出主张，主张正确率不能记为 100%；
   - 视觉题和正文题分开统计；
   - 不用候选集总数充当已评测样本量。

## 6. 反模式清单（常见错误）

- 把图注文字当作"视觉证据"；
- 凭领域常识补全读不清的数值/上标；
- 用论文印刷页码代替 PDF 物理页码；
- 先看模型答案再写金标准（锚定偏差）；
- 把 `unknown` 字段填 0 或空字符串（应保持 `null`）；
- 调试集和最终验收集混用（反复对同一批题改提示词后的结果不是独立验证）；
- 把"API 调用成功 / QC 通过"当作"答案正确"。
