## 定位

面向分子生物学、生物信息学、表观遗传学的单篇文献分析平台。Kimi 负责文字理解、综合分析和证据问答，Qwen `qwen3.8-flash` 负责图像输入分析；供应商端点与密钥仍由独立适配器配置。当前型号的可用性依据仓库 2026-10-03 的实际接口冒烟记录，不将套餐别名推定为所有 Qwen 端点通用型号。

核心产物：研究问题 → 假设 → 实验设计 → 结果 → 结论的故事架构；Figure / panel 间的论证顺序；对照、重复、统计与因果边界的证据支持；多方法比较论文的 dataset / split / metric / baseline / value / uncertainty / resource 条件与 benchmark 结论。缺失内容明确标记，不能推算或补造数值。

## 当前进度审计

- Phase 1 通用文本底座、Phase 2 PDF 和图表解析、Phase 3 API 与前端均已有代码及回归测试；保留现有行为。
- 报告已有正文理解、图表理解、事实核验三角色和条件结构修复；问答已有最多三轮检索/纠错、缺证据停止、视觉复核、缓存和后台任务生命周期。
- 已有 Kimi + Qwen 真实冒烟记录；细小标签误读、未核验断言从不确定性说明泄漏，以及视觉错误审计不够细仍是已知问题。
- 字符上限、选图上限和轮数限制不能替代 token 用量与预算；尚需统一调用账本、输出限额、推理策略和预算中止。
- 尚缺领域结构化故事线、图组 flow、benchmark 输出及对应交付闸门。
- 人工标注缺失影响准确率/召回率等效果结论，不影响自动工程测试、失败恢复、用量审计和接口验收。
