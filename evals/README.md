# Eval v1

本目录用于保存可复现的离线评估定义，而不是保存论文原文件或真实模型输出。

- `datasets/paper_v1/manifest.jsonl`：初始黄金集的清单、文件指纹和难度标签。
- `datasets/paper_v1/ANNOTATION_TEMPLATE.md`：人工确认的标注模板。
- `runs/`：后续真实模型和基线运行产生的本地结果；已被 Git 忽略。

## 数据与标注原则

1. 原始 PDF 位于仓库根目录 `ref_baseline/`，受 `.gitignore` 保护，不复制到本目录。
2. 文件的 `sha256` 用于保证评估时输入未被静默替换。
3. 人工金标准优先使用页码、章节名和简短定位说明，不直接依赖运行时生成的 `S1..Sn`。
4. `S1..Sn` 仅作为系统运行后的映射结果；结构修复后必须重新映射。
5. 不支持或冲突的主张应保留在金标准中，用于验证报告是否标注“待核验”。

## 当前范围

`paper_v1` 是四篇用户提供论文组成的校准集，暂不触发模型调用。第一版完成每篇 8--12 条核心主张的人工确认后，才开始真实模型评估。
