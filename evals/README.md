## 参考与评价契约

1. 源 PDF 保留在项目根目录 `ref_baseline/`；用 SHA-256 固定论文身份，物理页码从 1 开始，bbox 使用 PDF 点坐标。运行时 `S1..Sn` 不能替代源定位。
2. 当前参考是用户授权的 `ai_provisional`：由本会话助手独立阅读与标注。Kimi/Qwen 是被测模型，不生成或裁决参考；此身份与专家仲裁数据分开记录。
3. 被测清单只提供 PDF、问题与必要定位，不包含参考答案和 gold evidence。评价绑定参考指纹、run_id、answer_id 与回答指纹。
4. 每篇论文独立使用一份 standard 300,000 / 65,536 额度账本，四题共享；原生模型参数与执行额度分别保存。复跑必须使用新的输出目录，不覆盖原基线。
5. 内部 checker、工程通过和独立评分分别报告。逐项指标保留分子和分母，未填写评价不视为通过；缺失信息与正确拒答单独统计。
