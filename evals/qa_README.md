`qa_candidates.jsonl` 有 16 条未标注候选：QA-01–12 是待绑定论文的表观遗传学问题类型；QA-13–16 绑定本地 MoDorado PDF、图号和子图，图注页已用本地文本解析核对，但尚未人工读图标注、未运行问答。后四条属于生物信息/RNA 修饰，不冒称染色质表观遗传学覆盖。它们均不是金标准。
`qa_annotation_template.json` 是人工标注模板，所有空值保持“未完成”，不能默认为正确。

流程：选择有权使用的单篇 PDF → 记录 SHA256、题名、DOI → 绑定具体问题与图/子图 → 两位领域人员分别标注原文与视觉证据 → 仲裁分歧 → 冻结参考答案 → 单独记录真实调用 → 评价答案。
页码采用 PDF 的 1-based 物理页码；视觉证据记录可见观察和子图标签，不能把图注复述标为视觉金标准。

三类结果必须分开：

- **实现验证**：fake 模型、合成 PDF 和 API 回归，检查接口、轮次、定位、拒答和失败处理。
- **真实调用**：记录模型版本、视觉配置、日期、请求及后端答案 ID；调用成功不等于回答正确。
- **效果验证**：只有冻结人工参考后才能计算逐主张正确率、引用正确率、目标子图对齐、证据召回与拒答正确率；分别报告样本数与分母，不用候选集大小充当已评测样本量。

本轮仅完成第一类与标注材料准备；无新增真实问答调用，无专家效果评分。既有全文报告/视觉自检的历史真实调用不能算作问答验证。

## 工程批量运行

`qa_smoke.jsonl` 另列四个工程冒烟场景（正文、子图、缺图、无视觉降级），复用已有本地 PDF；它们也不是专家效果样本。

```bash
# 默认不调用模型
bash scripts/run.sh python scripts/run_qa_batch.py --output evals/runs/qa-preflight
# 只准备检查四个冒烟场景
bash scripts/run.sh python scripts/run_qa_batch.py --manifest evals/qa_smoke.jsonl --output evals/runs/qa-engineering-preflight
# 获得数据发送授权后才添加 --real；可用 --ids QA-13,QA-14 缩小候选范围
```

批量结果保留独立 run_id 清单、任务/答案 ID、审计路径与确定性工程检查。未绑定/指纹不符不调用，配置错误与运行错误分别记录，`expert_evaluation` 保持 `not_evaluated`。后台执行有超时和进程终止，不使用后台遗留线程冒充已经停止。

截至本次工程验收，真实冒烟因具体 PDF/外部模型目的地的数据发送确认待定而未执行；四个无模型准备检查已通过。详细状态见 [工程验收文档](../docs/qa-engineering.md) 和 [恢复断点](../docs/QA_AGENT_P0_P2_CHECKPOINT_2026-09-28.md)。
